# TSUGU AI

事業承継に向き合う「先代」と「後継者」が、それぞれ AI 面談で考えを言葉にし、**双方が共有を許可した回答だけ**を比べて認識のずれを見つけ、後継者の学習プランと90日行動計画につなげるサービスです。

「Built with Claude: Japan 2026」ハッカソン応募作品です。

> デモに登場する会社・人物はすべて架空です。AI の出力は参考情報であり、継ぐ／継がない、税務・法務・融資・企業価値についての判断は専門家にご確認ください。

## デモの流れ（予定）

1. 先代が AI 面談で回答する
2. 後継者が AI 面談で回答する
3. 双方が共有を許可した回答だけで比較し、AI が認識差を「追加確認が必要な点」として提示する
4. 診断結果を受けて後継者の学習プランが変わる
5. 90日行動計画ができる

## 技術構成

- Next.js（App Router）+ TypeScript
- Vercel（公開）
- Turso（データベース）
- Claude API（AI 面談・認識差の説明・計画づくり）

非公開の回答は、内容も存在もサーバー側で絞り込み、相手の画面には送りません。

## ローカルでの起動

```bash
npm install
npm run dev
```

`.env.local`（Git には含めません）に次の変数を設定します。

| 変数名 | 内容 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API キー（サーバー側でのみ使用） |
| `CLAUDE_MODEL` | 使用するモデル名（省略時は `lib/config.ts` の既定値） |

Claude API の接続確認：`npm run check:claude`

## 開発について

- 開発にはオーナー自作の Claude Code 開発チーム定義（CTO＋専門サブエージェント8名、`.claude/agents/`）を使用しています。
- これらは開発を補助するための設定ファイルであり、アプリケーションのコードはすべてハッカソン期間中（2026-11-02 12:00 以降）に新規作成しました。
- 既存プロジェクト（他のアプリや既存の AI マネージャー）のコードは流用していません。
