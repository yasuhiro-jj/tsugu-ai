# TSUGU AI 2.0（試作）実装メモ

後継者が決まっていない飲食店の経営者が、一人で面談し、載せる項目を自分で選び、相談資料の下書きを作る試作。
仕様の正は Notion（「04｜継続開発ロードマップ・着手指示書案」ほか）。ここには実装の要点だけを書く。

## いまの状態（段階2：架空データの試作）

- **架空の情報だけ**を使う。実在のお店・人・金額を入力しない。
- **外部の AI・DB にはつながない。** 面談の返事と資料づくりはモック（偽の差し替え部品）、保存はメモリの中だけ。サーバーを止めると消える。
- **本人認証はまだない。** httpOnly クッキーのセッション ID は「同じブラウザの続き」を見分けるだけ。実データを扱う前に、認証・認可・削除・監査を段階3で設計し、第三者の診断を受ける。
- ハッカソン版（既存の画面・API・DB・鍵）は変更していない。

## 置き場所（新規追加のみ）

| 場所 | 中身 |
| --- | --- |
| `app/v2/` | 画面（入口・面談・内容の確認・選択肢・載せる項目・資料の下書き） |
| `app/api/v2/session/` | API（1本） |
| `lib/v2/` | 処理（`service.ts`）、固定の文言（`content.ts`）、モック（`mock.ts`）、メモリ保存（`store.ts`） |
| `components/v2/` | 画面の部品 |
| `tests/v2/` | テスト |

`lib/v2`・`components/v2`・`app/v2`・`app/api/v2` から、既存の `lib/*.ts`（DB・Claude API を含む）は読み込まない。
`tests/v2/leak.test.ts` が読み込み先を調べて確認している。

## 画面の流れ

入口 → 面談（7テーマ）→ 内容の確認 → 準備リスト（11分野）→ 選択肢 → 資料に載せる項目 → 資料の下書き → 次の一歩

- 面談のテーマと最初の質問は、Notion「05｜TSUGU AI 2.0」の「面談テーマと質問例」の表のとおり（`lib/v2/content.ts`）。
- 準備リストは、分野ごとに「まだ確認していません／確認済み／要確認／不明」と「次に確認すること」を本人が整理する。
  「確認済み」は本人の申告として扱い、何で確かめたか（資料名・時点）が未記入ならその旨を資料に出す。
- 次の一歩は、準備リストで「要確認」「不明」にした分野・書いた「次に確認すること」と、選んだ相談先から候補を作る（`lib/v2/next-steps.ts`）。
  本人が「やる／今は保留」と、誰が・いつ頃を選ぶ。本人用のメモで、相談資料には入れない。
- 内容の確認で本人の発言を「消す」と、回答の原文・会話の記録・AI がその言葉を引用した一文も消える（`forgetAnswer`）。
  そのテーマの答えが1つも残らなければ、「答えが残っていません」を未確認として残す。
- 選択肢の画面は、準備リストの状況に応じて「まだ確かめていないこと」を出す（`lib/v2/option-guides.ts`）。
  どの道が合うかは判断せず、順位も付けない。確かめていない分野があれば「判断は保留」と示す。
- 見た目は Notion「共通デザイン基準｜Cursor風エディトリアルUI」を 2.0 の画面にだけ適用している（`app/v2/v2.css`）。
  基準の色のままでは文字が読みにくい組み合わせ（主要ボタン・補助の文字・注意の文字）は、読みやすさを優先して濃い色に調整した。
  書体は端末にあるものだけを使い、外部から読み込まない。

## 守っている約束と、その場所

- 資料生成に渡すのは、本人が「載せる」に印をつけた項目だけ：`lib/v2/service.ts` の `buildReportInput`
- 「載せる」の初期値はすべて未選択：`buildReviewItems`・`setOptions`
- 内容や選択を変えたら、古い資料は破棄する：`editItem`・`removeItem`・`setOptions`・`setReportSettings`
- 未確認をゼロや「問題なし」に変えない／本人の発言は入力したまま：`buildReviewItems`・`prepText`
- 準備リストも、載せると選んだ分野だけが資料に入る。内容が変わった分野は「載せる」を外す：`setPrep`
- 失敗したら保存せず、作り足さず、やり直し方を伝える：`answer`・`generateReport`
- 自動送信・共有 URL は作らない（操作の一覧にない）：`lib/v2/dispatch.ts`
- 回答・資料の本文をログに出さない：`app/api/v2/session/route.ts`

## 確かめ方

```bash
npm test
```

```bash
npm run dev
```

ブラウザで `/v2` を開く（鍵や DB の設定は不要）。
